# Notes

Interface web para um aplicativo de anotações com autenticação de usuários.

## Getting Started

### Requirements

- Vscode
- Node
- Next

### Installation

```bash
git clone https://github.com/code043/nextpad.git
cd nextpad
npm install
npm run dev
```
